- python 3.8 or later 

### Install python using Miniconda 

1) Download and install Mininconda from [here]()

2) Create a new env using the following command: 

```bash 
$ conda create -n mini-rag python=3.8
```

3)Activate env:

```bash
$ conda activate mini-rag 
```
